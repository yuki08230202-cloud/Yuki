# API 実現可能性の検証結果（2026-10-13 時点）

## 検証方法と範囲

| 区分 | 内容 |
|---|---|
| 仕様の検証（実施済み） | Chatwork 公式 API 仕様（`chatwork/api` リポジトリの RAML 定義）、Chatwork Webhook ドキュメント、Indeed Partner Docs（docs.indeed.com）を確認しました |
| 実地の検証（未実施） | この開発環境からは `api.chatwork.com` に接続できません（ネットワークポリシーで遮断されています）。本番トークンを設定した環境で `python -m enpra.cli verify` を実行し、結果を本ページ末尾の表に記入してください。このコマンドは**読み取りのみ**で、送信や変更は行いません |

凡例：◎ 公式 API で実装済み ／ ○ 代替方式で実装済み ／ △ 一部制約あり ／ × 公式 API なし

## 一覧：実装可能な部分と制約のある部分

| # | 機能 | 判定 | 使う API ／ 方式 | 制約と対応 |
|---|---|---|---|---|
| 1 | 管理者への通知（Chatwork） | ◎ | `POST /rooms/{room_id}/messages` | 管理者本人のトークンで送ると「自分の発言」扱いになり、通知が鳴りません。**通知専用の Bot アカウント**（`CHATWORK_NOTIFY_TOKEN`）から、管理者とのダイレクトチャットに送る構成を推奨します。Bot は管理者 1 名とだけコンタクトすれば足ります |
| 2 | 通知用 room_id の取得 | ◎ | `GET /rooms`、`GET /contacts`（各コンタクトの `room_id`） | `verify` コマンドで一覧を表示します |
| 3 | 代替通知（メール） | ◎ | SMTP（Gmail のアプリパスワード等） | Chatwork への送信が失敗したら自動で切り替えます。メールも失敗した場合は DB に記録し、管理画面に表示します |
| 4 | 毎日 19:00 の募集投稿 | ◎ | `POST /rooms/{id}/messages` ＋ Cloud Scheduler | 対象日ごとに一意のキーを持たせ、二重募集を防ぎます |
| 5 | 募集へのリアクション取得 | × | — | **公式 API にリアクション取得のエンドポイントはありません**（メッセージの項目にも含まれません）。Webhook のイベントも「メッセージ作成・編集・自分宛メンション」のみです |
| 5' | 参加表明の判定（代替） | ○ | `GET /rooms/{id}/messages?force=1` | 募集メッセージへの**「参加」返信**、またはグループへの「参加」投稿で判定します。取り消し（キャンセル／不参加）や重複を処理し、管理者・締切後・募集前の投稿は除外します。募集文にも「リアクションではなく返信で」と明記しています |
| 6 | 参加者への個別依頼 | ◎ | `POST /rooms/{direct_room_id}/messages` | ダイレクトチャットの room_id は `GET /contacts` から取得します。コンタクト外の人には、グループ内で `[To:]` 宛先付きで送ります（承認画面で警告を表示） |
| 7 | コンタクト数の確認 | ◎ | `GET /contacts`（件数） | 15 名以上で警告し、上限に達したら新規の承認を停止します。上限値は `CONTACT_LIMIT` で変更できます。「無料プランの組織外コンタクトは 20 名まで」という数値は、公開情報では確認できませんでした。Chatwork の管理画面で現行のプラン制限を確認してください |
| 8 | コンタクト申請の取得と承認 | ◎ | `GET /incoming_requests`、`PUT /incoming_requests/{id}` | 承認の実行直前に件数を再確認し、上限に達していれば実行しません。既存コンタクトの自動削除はしません（API にもコンタクト削除のエンドポイントはありません） |
| 9 | グループ招待 | ◎（注意あり） | `PUT /rooms/{id}/members` | **メンバー全体を置き換える API** です。現在のメンバーと権限を取得し、マージしてから送るように実装しています。追加できるのはコンタクト済みのユーザーだけで、実行するアカウントにはグループの管理者権限が必要です |
| 9' | 招待リンク | ◎ | `GET/POST /rooms/{id}/link` | コンタクト上限を回避する運用案（後述）で使えます |
| 10 | 質問の検知 | ◎ | Webhook（`message_created`／`mention_to_me`、署名検証あり）＋ 5 分ごとのポーリング | Webhook が無料プランで使えるかは要確認です。使えなくてもポーリングで動きます |
| 11 | AI 回答案 | ◎ | Claude API（任意。`LLM_ENABLED`） | FAQ に根拠がない質問や報酬・契約に関わる質問は、常に MODE A（変更不可）です |
| 12 | 終了報告の読み取り | ◎ | `GET /rooms/{id}/messages` | 無料プランは**直近 40 日・5,000 件**までしか閲覧できないため、読み取った実績はすぐ DB とスプレッドシートに保存します。月末の請求は Chatwork の履歴に依存しません |
| 13 | Google スプレッドシートの読み書き | ◎ | Sheets API v4（サービスアカウント） | 対象シートをサービスアカウントのメールアドレスに共有する必要があります。更新前後の値を保存し、復元できます |
| 14 | 請求書の送付（中島さん宛） | ◎ | `POST /rooms/{id}/files`（5MB まで） | 自動振込は実装しません |
| 15 | Indeed 応募者の取得 | △ | — | Indeed の公開 API は **ATS（採用管理システム）パートナー向け**です（Indeed Apply、Job Sync、Retrieve Candidates など）。利用には Developer Agreement と**事前の書面承認**が必要で、直接雇用主の小規模な利用は想定されていません |
| 15' | 応募者の取得（代替） | ○ | 管理画面への CSV 取込 | Indeed の管理画面からエクスポートまたは転記した応募者を取り込みます。既存の約 4 名もこの方法で登録します |
| 16 | Indeed 応募者へのメッセージ送信 | × | — | **雇用主から応募者へメッセージを送る公開 API は確認できませんでした**。画面の自動操作（スクレイピング）は Indeed の利用規約に抵触するおそれがあるため、実装しません |
| 16' | 応募者への案内（代替） | ○ | 承認 → 文面を用意 → Indeed 上で手動送信 → 「送信済み」で記録 | 未対応者の抽出、テンプレートの読み込み、Chatwork ID（i4snxm1oompx）への差し替え、一括・個別承認、履歴の記録まで自動化しています。人の操作は「貼り付けて送信」の 1 ステップだけです。API の権限が得られたら、送信部分だけを差し替えられる構造にしています |

## Indeed の今後の選択肢

1. **現行方式（推奨・実装済み）**：CSV 取込と承認後の手動送信。規約上の問題がなく、追加費用もかかりません。
2. **ATS 経由の連携**：Indeed と連携済みの ATS（例：HRMOS、ジョブカン採用管理、HERP など）を導入し、ATS 側の API や自動返信機能を使う方式です。月額費用がかかります。応募が月に数十件を超えたら検討してください。
3. **応募フォームでの自動返信**：Indeed の求人本文や応募完了後の案内に Chatwork ID を掲載し、新規応募者からのコンタクト申請を待つ方式です。この申請は `contacts-check` ジョブで自動的に承認依頼になります。

## コンタクト上限への対応（ワーカー数が増えた場合）

| 案 | 内容 | 費用 | 評価 |
|---|---|---|---|
| A. 有料プランへ移行 | ビジネスプラン等に切り替えて組織外コンタクトの上限をなくし、API やグループの機能もそのまま使う | 1 ユーザーあたり月額数百円〜（Chatwork の最新料金を確認してください） | ワーカーが 15 名を超えたら最有力 |
| B. グループ中心の運用 | 新規ワーカーには招待リンクでグループに参加してもらい、個別依頼はグループ内の `[To:]` で送る | 0 円 | コンタクトは増えませんが、個別のやり取りがグループに混ざります。個別依頼は既にこの方式へ自動で切り替わります |
| C. 休止中ワーカーの整理 | 稼働していないワーカーとのコンタクトを管理者が手動で削除する | 0 円 | システムからは自動削除しません |
| D. 別ツールへの移行 | Slack や LINE WORKS などに移る | 無料〜 | 移行の手間が大きいため、最終手段とします |
